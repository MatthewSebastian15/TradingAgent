# LLM Optimization Implementation Guide for TradingAgent

## 0. Tujuan Dokumen

Dokumen ini menjelaskan implementasi optimasi penggunaan LLM pada project **TradingAgent-dev** dengan fokus pada:

1. **Token reduction**: mengurangi ukuran prompt tanpa menghilangkan informasi penting.
2. **Prompt caching friendly refactor**: menyusun ulang prompt agar lebih mudah mendapat cache hit dari provider LLM.
3. **Exact LLM cache per agent**: menyimpan hasil LLM ketika prompt dan schema benar-benar identik.
4. **Semantic caching terbatas**: menyimpan hasil berbasis kemiripan makna hanya untuk area yang aman.
5. **Provider-level prompt caching**: memanfaatkan kemampuan caching dari OpenAI dan Gemini.
6. **LLM observability**: logging token, latency, cache hit/miss, fallback, dan agent cost estimate.

Dokumen ini dibuat untuk implementasi bertahap ke kode project saat ini, bukan desain teoritis yang mengambang di awan sambil menunggu engineer menangis.

## 2. Masalah Utama yang Perlu Diselesaikan

### 2.1 Prompt masih membawa data mentah terlalu besar

Saat ini prompt agent masih memasukkan data seperti:

```python
PRICE DATA:
{data.price_data}

FUNDAMENTALS:
{data.fundamentals}

BALANCE SHEET:
{data.balance_sheet}

CASH FLOW:
{data.cashflow}

INCOME STATEMENT:
{data.income_statement}
```

Di `pipeline_balanced_data.py`, beberapa field juga masih memakai limit besar, misalnya:

```python
price_data limit=14_000
fundamentals limit=12_000
balance_sheet limit=10_000
cashflow limit=10_000
income_statement limit=10_000
company_news limit=12_000
global_news limit=8_000
```

Masalahnya, LLM tidak selalu perlu membaca seluruh CSV atau statement mentah. UI/debug memang butuh data lengkap, tetapi prompt LLM cukup memakai ringkasan terstruktur.

### 2.2 Prefix prompt belum stabil

Prompt saat ini diawali dengan data dinamis:

```text
You are the Market Analyst for {ticker} on {trade_date}.
```

Untuk provider-level prompt caching, bagian awal prompt sebaiknya stabil. Ticker, tanggal, horizon, dan data sebaiknya diletakkan setelah blok instruksi statis.

### 2.3 Belum ada cache per call LLM

Project sudah punya final result cache, tetapi belum punya cache di level agent. Akibatnya jika satu pipeline diulang dengan prompt identik, semua agent tetap memanggil LLM lagi kecuali final result cache menangkap keseluruhan request.

### 2.4 Belum ada observability biaya/token yang cukup rinci

Saat ini sistem tahu jumlah call berdasarkan `LLMBudget`, tetapi belum mencatat secara detail:

- prompt character length,
- estimated input tokens,
- output tokens,
- cached tokens dari provider,
- latency per agent,
- exact cache hit/miss,
- semantic cache hit/miss,
- fallback usage,
- schema parse failure.

Tanpa data ini, optimasi hanya jadi aktivitas menebak-nebak. Teknologi modern, tapi tetap pakai firasat kalau tidak diberi meteran.

---

## 3. Target Arsitektur Akhir

Arsitektur optimasi yang disarankan:

```text
API Request
   |
   v
Existing Analysis Result Cache
   |
   v
Data Collection
   |
   +--> Raw Data for UI / Debug
   |
   +--> Compact Prompt Context for LLM
            |
            v
      Prompt Builder
      - static prefix first
      - dynamic request/data later
            |
            v
      _invoke_once()
      - usage logging start
      - exact cache lookup
      - optional semantic cache lookup for safe targets only
      - budget consume only on real LLM call
      - LLM call
      - parse structured output
      - cache store
      - usage logging finish
            |
            v
      Agent Output
            |
            v
      Final Portfolio Decision
```

Prinsip penting:

1. **Raw data tetap tersedia untuk UI/debug.**
2. **Prompt LLM memakai compact context.**
3. **Exact cache aman untuk semua agent selama prompt/schema benar-benar identik.**
4. **Semantic cache tidak boleh bebas dipakai untuk final trading decision.**
5. **Cache hit tidak boleh mengonsumsi `LLMBudget`.**
6. **Fallback output tidak boleh disimpan sebagai cache sukses.**
7. **Data quality warning harus tetap masuk ke prompt compact.**
8. **Provider-level prompt caching dibantu dengan struktur prompt yang stabil.**

---

## 4. Urutan Implementasi yang Disarankan

Jangan mulai dari semantic cache. Itu seperti memasang spoiler mobil sebelum remnya berfungsi.

Urutan yang benar:

| Phase | Fokus | Risiko | Dampak |
|---|---|---:|---:|
| Phase 1 | LLM usage logging | Rendah | Tinggi untuk observability |
| Phase 2 | Token reduction / compact context | Sedang | Sangat tinggi |
| Phase 3 | Prompt caching friendly refactor | Rendah-Sedang | Tinggi |
| Phase 4 | Exact LLM cache per agent | Sedang | Tinggi |
| Phase 5 | Semantic cache terbatas | Tinggi jika salah | Sedang-Tinggi |
| Phase 6 | Provider-level prompt caching tuning | Rendah | Sedang-Tinggi |
| Phase 7 | Testing, monitoring, rollout | Rendah | Wajib |

## 5.3 Isi file `llm_optimization/usage.py`

```python
from __future__ import annotations

import logging
import time
from dataclasses import dataclass, field
from typing import Any

logger = logging.getLogger(__name__)


@dataclass
class LLMUsageRecord:
    agent_name: str
    provider: str
    model: str
    schema_name: str
    prompt_chars: int
    estimated_input_tokens: int
    output_tokens: int | None = None
    cached_input_tokens: int | None = None
    latency_ms: float | None = None
    cache_layer: str | None = None
    cache_hit: bool = False
    fallback_used: bool = False
    parse_success: bool = False
    error: str | None = None
    extra: dict[str, Any] = field(default_factory=dict)


def estimate_tokens_from_text(text: str) -> int:
    # Approximation only. Enough for monitoring trend without adding tiktoken dependency.
    # For English/JSON-heavy prompts, 1 token ~= 3.5-4 chars. Use conservative divisor 4.
    return max(1, len(text or "") // 4)


def get_llm_identity(llm: Any) -> tuple[str, str]:
    provider = getattr(llm, "provider", None) or getattr(llm, "_llm_type", None) or llm.__class__.__name__
    model = (
        getattr(llm, "model_name", None)
        or getattr(llm, "model", None)
        or getattr(llm, "model_id", None)
        or "unknown"
    )
    return str(provider).lower(), str(model)


def extract_usage_metadata(result: Any) -> dict[str, Any]:
    """Best-effort extraction across LangChain/OpenAI/Gemini response objects."""
    metadata: dict[str, Any] = {}

    response_metadata = getattr(result, "response_metadata", None)
    if isinstance(response_metadata, dict):
        metadata.update(response_metadata)

    usage_metadata = getattr(result, "usage_metadata", None)
    if isinstance(usage_metadata, dict):
        metadata["usage_metadata"] = usage_metadata

    additional_kwargs = getattr(result, "additional_kwargs", None)
    if isinstance(additional_kwargs, dict):
        metadata["additional_kwargs"] = additional_kwargs

    return metadata


def normalize_usage_numbers(metadata: dict[str, Any]) -> tuple[int | None, int | None]:
    """Return (output_tokens, cached_input_tokens)."""
    output_tokens = None
    cached_input_tokens = None

    usage = metadata.get("usage_metadata") or metadata.get("token_usage") or metadata.get("usage")
    if isinstance(usage, dict):
        output_tokens = (
            usage.get("output_tokens")
            or usage.get("completion_tokens")
            or usage.get("candidates_token_count")
        )

        prompt_details = usage.get("prompt_tokens_details") or usage.get("input_token_details") or {}
        if isinstance(prompt_details, dict):
            cached_input_tokens = prompt_details.get("cached_tokens") or prompt_details.get("cache_read")

        cached_input_tokens = cached_input_tokens or usage.get("cached_content_token_count")

    return _safe_int(output_tokens), _safe_int(cached_input_tokens)


def _safe_int(value: Any) -> int | None:
    try:
        if value is None:
            return None
        return int(value)
    except (TypeError, ValueError):
        return None


def log_usage(record: LLMUsageRecord) -> None:
    logger.info(
        "LLM usage | agent=%s provider=%s model=%s schema=%s prompt_chars=%s est_input_tokens=%s "
        "output_tokens=%s cached_input_tokens=%s latency_ms=%.1f cache_layer=%s cache_hit=%s "
        "fallback=%s parse_success=%s error=%s",
        record.agent_name,
        record.provider,
        record.model,
        record.schema_name,
        record.prompt_chars,
        record.estimated_input_tokens,
        record.output_tokens,
        record.cached_input_tokens,
        record.latency_ms or 0.0,
        record.cache_layer,
        record.cache_hit,
        record.fallback_used,
        record.parse_success,
        record.error,
    )


class Timer:
    def __init__(self) -> None:
        self.started = time.perf_counter()

    def elapsed_ms(self) -> float:
        return (time.perf_counter() - self.started) * 1000
```

## 6.3 Isi `prompt_context.py`

```python
from __future__ import annotations

import csv
import json
import math
from io import StringIO
from statistics import mean
from typing import Any


def safe_json_dumps(value: Any, *, max_chars: int | None = None) -> str:
    text = json.dumps(value, ensure_ascii=False, indent=2, default=str)
    if max_chars is not None and len(text) > max_chars:
        return text[:max_chars].rstrip() + "\n[TRUNCATED_FOR_PROMPT_CONTEXT]"
    return text


def _to_float(value: Any) -> float | None:
    try:
        if value is None or value == "":
            return None
        number = float(str(value).replace(",", ""))
        if math.isnan(number) or math.isinf(number):
            return None
        return number
    except (TypeError, ValueError):
        return None


def parse_ohlcv_csv(price_data: str) -> list[dict[str, Any]]:
    lines = [line for line in (price_data or "").splitlines() if line.strip() and not line.lstrip().startswith("#")]
    if not lines:
        return []

    rows: list[dict[str, Any]] = []
    reader = csv.DictReader(StringIO("\n".join(lines)))
    for raw in reader:
        date = (raw.get("Date") or raw.get("") or "").strip()
        close = _to_float(raw.get("Close") or raw.get("Adj Close"))
        open_ = _to_float(raw.get("Open"))
        high = _to_float(raw.get("High"))
        low = _to_float(raw.get("Low"))
        volume = _to_float(raw.get("Volume"))
        if not date or close is None:
            continue
        rows.append(
            {
                "date": date[:10],
                "open": open_,
                "high": high,
                "low": low,
                "close": close,
                "volume": volume,
            }
        )
    return rows


def _pct_change(start: float | None, end: float | None) -> float | None:
    if start is None or end is None or start == 0:
        return None
    return round(((end - start) / start) * 100, 2)


def build_market_context(data: Any, *, recent_candle_limit: int = 10) -> dict[str, Any]:
    rows = parse_ohlcv_csv(data.price_data)
    closes = [row["close"] for row in rows if row.get("close") is not None]
    volumes = [row["volume"] for row in rows if row.get("volume") is not None]

    last = rows[-1] if rows else {}
    last_close = last.get("close") or data.last_close_price

    high_values = [row["high"] for row in rows if row.get("high") is not None]
    low_values = [row["low"] for row in rows if row.get("low") is not None]

    context = {
        "ticker": data.ticker,
        "trade_date": data.trade_date,
        "time_horizon_months": data.time_horizon_months,
        "last_close": last_close,
        "last_close_as_of": data.last_close_price_as_of,
        "price_source": data.last_close_price_source,
        "rows_available": len(rows),
        "window_start": rows[0]["date"] if rows else None,
        "window_end": rows[-1]["date"] if rows else None,
        "returns_percent": {
            "5d": _pct_change(closes[-6], closes[-1]) if len(closes) >= 6 else None,
            "20d": _pct_change(closes[-21], closes[-1]) if len(closes) >= 21 else None,
            "60d": _pct_change(closes[-61], closes[-1]) if len(closes) >= 61 else None,
        },
        "window_high": max(high_values) if high_values else None,
        "window_low": min(low_values) if low_values else None,
        "average_volume_20d": round(mean(volumes[-20:]), 2) if len(volumes) >= 1 else None,
        "recent_candles": rows[-recent_candle_limit:],
        "price_chart_summary": _compact_price_chart(data.price_chart),
        "technical_indicators": _compact_text_block(data.technical_indicators, max_chars=3500),
        "data_quality": data.data_quality.model_dump() if data.data_quality else {},
    }
    return context


def _compact_price_chart(price_chart: dict[str, Any] | None) -> dict[str, Any]:
    if not isinstance(price_chart, dict):
        return {"available": False}
    return {
        "available": bool(price_chart),
        "summary": price_chart.get("summary"),
        "source": price_chart.get("source"),
        "currency": price_chart.get("currency"),
        "points_count": len(price_chart.get("points") or []),
        "latest_point": (price_chart.get("points") or [])[-1] if price_chart.get("points") else None,
    }


def _compact_text_block(value: str, *, max_chars: int) -> str:
    text = "\n".join(line.rstrip() for line in str(value or "").splitlines() if line.strip())
    if len(text) <= max_chars:
        return text
    return text[:max_chars].rstrip() + "\n[TRUNCATED_FOR_PROMPT_CONTEXT]"


def build_news_context(data: Any, *, max_company_items: int = 5, max_macro_items: int = 3) -> dict[str, Any]:
    related_items = []
    if isinstance(data.related_news, dict):
        related_items = data.related_news.get("items") or []

    normalized_items = []
    for item in related_items[: max_company_items + max_macro_items]:
        if not isinstance(item, dict):
            continue
        normalized_items.append(
            {
                "title": item.get("title"),
                "publisher": item.get("publisher"),
                "published_at": item.get("published_at"),
                "source": item.get("source"),
                "event_type": item.get("event_type"),
                "summary": item.get("summary"),
                "relevance_score": item.get("relevance_score"),
                "relevance_reason": item.get("relevance_reason"),
            }
        )

    return {
        "ticker": data.ticker,
        "trade_date": data.trade_date,
        "time_horizon_months": data.time_horizon_months,
        "company_news_top_items": normalized_items[:max_company_items],
        "macro_news_summary": _compact_text_block(data.global_news, max_chars=1800),
        "insider_transactions": _compact_text_block(data.insider_transactions, max_chars=1200),
        "news_sentiment": _compact_text_block(data.news_sentiment, max_chars=1200),
        "social_sentiment": _compact_text_block(data.social_sentiment, max_chars=1000),
        "data_quality": data.data_quality.model_dump() if data.data_quality else {},
    }


def build_fundamentals_context(data: Any) -> dict[str, Any]:
    return {
        "ticker": data.ticker,
        "trade_date": data.trade_date,
        "time_horizon_months": data.time_horizon_months,
        "company_profile": data.company_profile or {"available": False},
        "financial_highlights": data.financial_highlights or {"available": False},
        "fundamentals_summary": _compact_text_block(data.fundamentals, max_chars=2500),
        "statement_samples": {
            "balance_sheet": _compact_text_block(data.balance_sheet, max_chars=1800),
            "cashflow": _compact_text_block(data.cashflow, max_chars=1800),
            "income_statement": _compact_text_block(data.income_statement, max_chars=1800),
        },
        "event_risk": _compact_text_block(data.event_risk, max_chars=1200),
        "recommendation_trends": _compact_text_block(data.recommendation_trends, max_chars=1200),
        "data_quality": data.data_quality.model_dump() if data.data_quality else {},
    }


def build_prompt_context(data: Any) -> dict[str, Any]:
    return {
        "market": build_market_context(data),
        "news_social": build_news_context(data),
        "fundamentals": build_fundamentals_context(data),
    }
```

## 8.3 Isi `llm_cache/exact_cache.py`

```python
from __future__ import annotations

import json
import sqlite3
import threading
import time
from pathlib import Path
from typing import Any

from pydantic import BaseModel

from tradingagents.llm_cache.keys import ExactLLMCacheKey

SCHEMA_VERSION = 1


class ExactLLMCache:
    def __init__(self, db_path: str, ttl_seconds: int, max_entries: int) -> None:
        self.db_path = Path(db_path)
        self.ttl_seconds = max(1, int(ttl_seconds))
        self.max_entries = max(1, int(max_entries))
        self.db_path.parent.mkdir(parents=True, exist_ok=True)
        self._lock = threading.RLock()
        self._ensure_schema()

    def get(self, key: ExactLLMCacheKey, schema: type[BaseModel]) -> BaseModel | None:
        now = time.time()
        key_json = _dumps(key.as_dict())
        with self._lock, self._connect() as conn:
            row = conn.execute(
                "SELECT expires_at, value FROM llm_exact_cache WHERE cache_key = ?",
                (key_json,),
            ).fetchone()
            if row is None:
                return None
            expires_at, value = row
            if float(expires_at) <= now:
                conn.execute("DELETE FROM llm_exact_cache WHERE cache_key = ?", (key_json,))
                return None
            try:
                parsed = schema.model_validate(json.loads(value))
            except Exception:
                conn.execute("DELETE FROM llm_exact_cache WHERE cache_key = ?", (key_json,))
                return None
            conn.execute(
                "UPDATE llm_exact_cache SET last_accessed_at = ? WHERE cache_key = ?",
                (now, key_json),
            )
            return parsed

    def set(self, key: ExactLLMCacheKey, value: BaseModel) -> None:
        now = time.time()
        expires_at = now + self.ttl_seconds
        key_json = _dumps(key.as_dict())
        value_json = value.model_dump_json()
        with self._lock, self._connect() as conn:
            conn.execute("BEGIN IMMEDIATE")
            conn.execute(
                """
                INSERT OR REPLACE INTO llm_exact_cache
                (cache_key, expires_at, last_accessed_at, value)
                VALUES (?, ?, ?, ?)
                """,
                (key_json, expires_at, now, value_json),
            )
            self._evict(conn)

    def stats(self) -> dict[str, Any]:
        with self._lock, self._connect() as conn:
            count = conn.execute(
                "SELECT COUNT(*) FROM llm_exact_cache WHERE expires_at > ?",
                (time.time(),),
            ).fetchone()[0]
        return {
            "backend": "sqlite",
            "path": str(self.db_path),
            "entries": int(count),
            "ttl_seconds": self.ttl_seconds,
            "max_entries": self.max_entries,
        }

    def _connect(self) -> sqlite3.Connection:
        conn = sqlite3.connect(self.db_path, timeout=30)
        conn.execute("PRAGMA busy_timeout = 30000")
        return conn

    def _ensure_schema(self) -> None:
        with self._lock, self._connect() as conn:
            conn.execute("PRAGMA journal_mode = WAL")
            version = int(conn.execute("PRAGMA user_version").fetchone()[0])
            if version > SCHEMA_VERSION:
                raise RuntimeError("llm exact cache schema is newer than supported")
            if version < 1:
                conn.execute(
                    """
                    CREATE TABLE IF NOT EXISTS llm_exact_cache (
                        cache_key TEXT PRIMARY KEY,
                        expires_at REAL NOT NULL,
                        last_accessed_at REAL NOT NULL,
                        value TEXT NOT NULL
                    )
                    """
                )
                conn.execute("CREATE INDEX IF NOT EXISTS idx_llm_exact_expires ON llm_exact_cache (expires_at)")
                conn.execute("CREATE INDEX IF NOT EXISTS idx_llm_exact_last_accessed ON llm_exact_cache (last_accessed_at)")
                conn.execute(f"PRAGMA user_version = {SCHEMA_VERSION}")

    def _evict(self, conn: sqlite3.Connection) -> None:
        now = time.time()
        conn.execute("DELETE FROM llm_exact_cache WHERE expires_at <= ?", (now,))
        rows = conn.execute(
            "SELECT cache_key FROM llm_exact_cache ORDER BY last_accessed_at DESC LIMIT -1 OFFSET ?",
            (self.max_entries,),
        ).fetchall()
        if rows:
            conn.executemany("DELETE FROM llm_exact_cache WHERE cache_key = ?", rows)


def _dumps(value: Any) -> str:
    return json.dumps(value, sort_keys=True, ensure_ascii=False, separators=(",", ":"), default=str)


_CACHE_INSTANCE: ExactLLMCache | None = None
_CACHE_LOCK = threading.Lock()


def get_exact_llm_cache(config: dict[str, Any]) -> ExactLLMCache | None:
    global _CACHE_INSTANCE
    if not bool(config.get("llm_exact_cache_enabled", False)):
        return None

    db_path = str(config.get("llm_exact_cache_db_path") or ".cache/llm_exact_cache.sqlite3")
    ttl_seconds = int(config.get("llm_exact_cache_ttl_seconds") or 1800)
    max_entries = int(config.get("llm_exact_cache_max_entries") or 1024)

    with _CACHE_LOCK:
        if _CACHE_INSTANCE is None or str(_CACHE_INSTANCE.db_path) != db_path:
            _CACHE_INSTANCE = ExactLLMCache(db_path, ttl_seconds, max_entries)
        return _CACHE_INSTANCE
```

Isi awal cukup kerangka berikut:

```python
from __future__ import annotations

import json
import math
import sqlite3
import threading
import time
from pathlib import Path
from typing import Any


def cosine_similarity(a: list[float], b: list[float]) -> float:
    if not a or not b or len(a) != len(b):
        return 0.0
    dot = sum(x * y for x, y in zip(a, b))
    norm_a = math.sqrt(sum(x * x for x in a))
    norm_b = math.sqrt(sum(y * y for y in b))
    if norm_a == 0 or norm_b == 0:
        return 0.0
    return dot / (norm_a * norm_b)


class SemanticCache:
    def __init__(self, db_path: str, ttl_seconds: int, max_entries: int, threshold: float) -> None:
        self.db_path = Path(db_path)
        self.ttl_seconds = ttl_seconds
        self.max_entries = max_entries
        self.threshold = threshold
        self.db_path.parent.mkdir(parents=True, exist_ok=True)
        self._lock = threading.RLock()
        self._ensure_schema()

    def find(
        self,
        *,
        namespace: str,
        guard: dict[str, Any],
        embedding: list[float],
    ) -> dict[str, Any] | None:
        now = time.time()
        guard_json = _dumps(guard)
        with self._lock, self._connect() as conn:
            rows = conn.execute(
                """
                SELECT id, embedding, value
                FROM llm_semantic_cache
                WHERE namespace = ? AND guard_json = ? AND expires_at > ?
                ORDER BY last_accessed_at DESC
                LIMIT 100
                """,
                (namespace, guard_json, now),
            ).fetchall()

            best_id = None
            best_value = None
            best_score = 0.0
            for row_id, embedding_json, value_json in rows:
                old_embedding = json.loads(embedding_json)
                score = cosine_similarity(embedding, old_embedding)
                if score > best_score:
                    best_score = score
                    best_id = row_id
                    best_value = json.loads(value_json)

            if best_id is not None and best_score >= self.threshold:
                conn.execute(
                    "UPDATE llm_semantic_cache SET last_accessed_at = ? WHERE id = ?",
                    (now, best_id),
                )
                return {"value": best_value, "similarity": best_score}

        return None

    def set(
        self,
        *,
        namespace: str,
        guard: dict[str, Any],
        embedding: list[float],
        value: dict[str, Any],
    ) -> None:
        now = time.time()
        with self._lock, self._connect() as conn:
            conn.execute("BEGIN IMMEDIATE")
            conn.execute(
                """
                INSERT INTO llm_semantic_cache
                (namespace, guard_json, embedding, value, expires_at, last_accessed_at)
                VALUES (?, ?, ?, ?, ?, ?)
                """,
                (
                    namespace,
                    _dumps(guard),
                    json.dumps(embedding, separators=(",", ":")),
                    json.dumps(value, ensure_ascii=False, separators=(",", ":"), default=str),
                    now + self.ttl_seconds,
                    now,
                ),
            )
            self._evict(conn)

    def _connect(self) -> sqlite3.Connection:
        conn = sqlite3.connect(self.db_path, timeout=30)
        conn.execute("PRAGMA busy_timeout = 30000")
        return conn

    def _ensure_schema(self) -> None:
        with self._lock, self._connect() as conn:
            conn.execute("PRAGMA journal_mode = WAL")
            conn.execute(
                """
                CREATE TABLE IF NOT EXISTS llm_semantic_cache (
                    id INTEGER PRIMARY KEY AUTOINCREMENT,
                    namespace TEXT NOT NULL,
                    guard_json TEXT NOT NULL,
                    embedding TEXT NOT NULL,
                    value TEXT NOT NULL,
                    expires_at REAL NOT NULL,
                    last_accessed_at REAL NOT NULL
                )
                """
            )
            conn.execute("CREATE INDEX IF NOT EXISTS idx_semantic_guard ON llm_semantic_cache (namespace, guard_json)")
            conn.execute("CREATE INDEX IF NOT EXISTS idx_semantic_expires ON llm_semantic_cache (expires_at)")

    def _evict(self, conn: sqlite3.Connection) -> None:
        now = time.time()
        conn.execute("DELETE FROM llm_semantic_cache WHERE expires_at <= ?", (now,))
        rows = conn.execute(
            "SELECT id FROM llm_semantic_cache ORDER BY last_accessed_at DESC LIMIT -1 OFFSET ?",
            (self.max_entries,),
        ).fetchall()
        if rows:
            conn.executemany("DELETE FROM llm_semantic_cache WHERE id = ?", rows)


def _dumps(value: Any) -> str:
    return json.dumps(value, sort_keys=True, ensure_ascii=False, separators=(",", ":"), default=str)
```

# PHASE 6 — Provider-Level Prompt Caching

## 10. Tujuan Phase 6

Memanfaatkan caching bawaan provider LLM.

Catatan penting:

- OpenAI prompt caching bekerja otomatis untuk prompt eligible dan sangat bergantung pada exact prefix match.
- Gemini memiliki implicit caching untuk model Gemini baru, dan explicit context caching dapat digunakan jika memakai direct Gemini SDK.
- Karena project saat ini memakai LangChain wrapper, jangan asumsikan semua parameter provider langsung didukung tanpa validasi versi library.

## 10.1 OpenAI prompt caching

### Yang perlu dilakukan di project

1. Pastikan prompt memiliki static prefix stabil.
2. Letakkan dynamic ticker/date/data di akhir.
3. Jangan ubah wording static prompt setiap request.
4. Jangan generate random instruction/order.
5. Log cached token jika provider mengembalikan metadata.

### Optional passthrough config

File:

## 10.2 Gemini implicit caching

Untuk Gemini:

1. Static context harus ada di awal prompt.
2. Request yang mirip harus dikirim dalam waktu berdekatan.
3. Log `usage_metadata` jika tersedia.
4. Jangan berharap explicit cache bekerja otomatis lewat LangChain wrapper.

File:

```text
backend/tradingagents-core/tradingagents/llm_clients/google_client.py
```

Tambahkan extraction metadata tidak di client, melainkan cukup di Phase 1 `usage.py` agar provider-agnostic.

## 10.3 Gemini explicit caching optional

Explicit caching lebih cocok jika Anda punya konteks besar yang dipakai berulang, misalnya:

- static system instruction besar,
- company profile besar,
- dokumen annual report,
- file PDF panjang,
- reusable prompt corpus.

Untuk pipeline saat ini, explicit Gemini caching **belum menjadi prioritas**, karena data tiap ticker/tanggal cepat berubah dan project memakai LangChain wrapper. Prioritaskan:

1. compact context,
2. prompt prefix stability,
3. exact cache.

## 10.4 Acceptance Criteria Phase 6

- Static prefix sama untuk ticker berbeda.
- Log mampu membaca cached token metadata jika provider memberikannya.
- OpenAI/Gemini tetap berjalan walaupun metadata cache tidak tersedia.
- Tidak ada parameter provider yang menyebabkan startup/runtime error.

# 14. Risiko dan Mitigasi

## 14.1 Risiko: Compact context menghilangkan informasi penting

Mitigasi:

- Data quality wajib tetap dikirim.
- Recent candles tetap dikirim.
- Financial highlights wajib dipakai.
- Statement sample tetap dikirim terbatas.
- Bandingkan output sebelum/sesudah untuk BBCA, BBRI, TLKM, BREN, TPIA.

## 14.2 Risiko: Cache menyimpan output fallback

Mitigasi:

- Simpan cache hanya setelah `parsed is not None`.
- Jangan cache saat exception.
- Jangan cache fallback.

## 14.3 Risiko: Semantic cache memberi rekomendasi basi

Mitigasi:

- Disabled by default.
- Jangan terapkan ke Portfolio Manager dan Trader.
- Guard harus menyertakan ticker/date/horizon/data_hash.
- Threshold minimal 0.97.

## 14.4 Risiko: Provider passthrough parameter tidak didukung LangChain

Mitigasi:

- Tambahkan parameter OpenAI caching hanya setelah validasi versi `langchain-openai`.
- Jika error, rollback passthrough.
- Prompt refactor tetap berguna walaupun parameter khusus tidak dipakai.

## 14.5 Risiko: Cache DB bertambah besar

Mitigasi:

- Pakai TTL.
- Pakai `max_entries`.
- Eviction by `last_accessed_at`.
- Simpan structured output JSON, bukan raw provider response besar.

# 17. Final Recommendation

Implementasi paling aman untuk TradingAgent adalah:

```text
Phase 1: Usage logging
Phase 2: Token reduction / compact prompt context
Phase 3: Prompt caching friendly refactor
Phase 4: Exact LLM cache
```

Semantic caching sebaiknya masuk belakangan dan tetap disabled by default sampai test guard benar-benar kuat.

Untuk aplikasi trading, target utama bukan sekadar membuat LLM lebih murah. Target sebenarnya adalah:

1. output tetap akurat,
2. keputusan tidak basi,
3. data quality tetap terlihat,
4. latency turun,
5. biaya turun,
6. fallback tidak meningkat,
7. sistem mudah diaudit.

Jika harus memilih hanya satu optimasi pertama, pilih **token reduction**. Itu paling aman, paling langsung terasa, dan paling kecil kemungkinan membuat sistem mengembalikan jawaban usang yang terdengar meyakinkan.
