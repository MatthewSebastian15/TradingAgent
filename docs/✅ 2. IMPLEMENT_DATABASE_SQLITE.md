# IMPLEMENT_ANALYSIS_DATABASE_SQLITE.md

## Tujuan

Dokumen ini menjelaskan rencana implementasi database SQLite untuk menyimpan hasil analisis TradingAgent secara permanen, terutama untuk:

1. Menyimpan **Recent Analyses** tidak lagi hanya di `localStorage`.
2. Membuat hasil analisis tetap bisa dibuka ulang walaupun backend/browser restart.
3. Membuat **Preview HTML** dan **Export PDF** membaca data dari hasil analisis yang sama.
4. Membantu debugging UI dengan data yang konsisten antara analisis asli, mock data, preview HTML, dan export PDF.
5. Menyediakan fondasi audit history agar hasil lama bisa dibandingkan dengan hasil baru.

Implementasi yang disarankan adalah **SQLite** karena project ini bersifat personal/dev. SQLite cukup ringan, tidak butuh server database terpisah, mudah dipakai di Docker, dan cocok untuk menyimpan history analisis. Tidak semua hal perlu PostgreSQL, karena tidak semua project personal harus berubah menjadi mini-bank yang menyiksa pemiliknya sendiri.

---

## Ringkasan kondisi project saat ini

Project saat ini sudah memiliki beberapa mekanisme penyimpanan, tetapi sifatnya belum ideal untuk history permanen.

| Bagian | Lokasi | Kondisi saat ini | Masalah |
|---|---|---|---|
| Recent Analyses frontend | `frontend/src/components/AnalysisWorkspace.jsx` | Disimpan ke `localStorage` berdasarkan `historyKey` | Hilang per browser, sulit audit, tidak bisa jadi sumber utama untuk export |
| Job result backend | `backend/routes/jobs.py`, `backend/analysis_cache.py` | Job result disimpan di `AnalysisJobStore` dan persistent cache TTL | TTL pendek, lebih cocok untuk cache/job recovery, bukan history permanen |
| SQLite cache existing | `backend/persistent_cache.py` | `SQLiteTTLCache` untuk cache TTL JSON | Nama dan behavior cache, bukan database domain analysis permanen |
| Report HTML/PDF | `backend/routes/reports.py`, `backend/services/report_service.py` | Mengambil result lewat `get_analysis_result_for_report(request_id)` dari `JOB_STORE` | Kalau job/cache expired, report tidak bisa dibuat lagi |
| Mock analysis | `frontend/src/mockData.js`, `frontend/src/pages/AnalysisMock.jsx` | Dummy data frontend | Harus disamakan dengan contract hasil analisis asli dan export payload |

Kesimpulan: database baru sebaiknya **tidak mengganti cache existing**, melainkan menjadi **analysis history repository** yang menyimpan hasil final analisis secara permanen atau semi-permanen.

## Target arsitektur baru

### Sebelum

```text
Analysis result
  -> Backend job store / cache TTL
  -> Frontend localStorage
  -> Preview HTML/PDF ambil dari JOB_STORE
```

Masalahnya: jika `JOB_STORE` expired atau backend restart tanpa cache valid, preview/export bisa gagal. `localStorage` juga tidak bisa diandalkan sebagai sumber kebenaran.

### Sesudah

```text
Analysis result
  -> Backend normalizes response
  -> Save to SQLite analysis database
  -> Frontend receives same response
  -> Recent Analyses reads from database API
  -> Detail page reads by request_id from database API
  -> Preview HTML reads same database result
  -> Export PDF reads same database result
  -> Mock data follows the same result contract
```

Database menjadi sumber utama untuk hasil final analisis. `localStorage` boleh tetap ada sebagai cache ringan, tetapi bukan sumber kebenaran utama.

---

## Prinsip desain

1. **Jangan menyimpan ulang hasil dengan fetch market data baru.**
   Export HTML/PDF harus memakai snapshot hasil analisis yang sudah disimpan, bukan menjalankan analisis ulang.

2. **Simpan full JSON result.**
   Jangan hanya simpan field kecil seperti `ticker`, `decision`, `entry`, dan `stop_loss`. Layout UI bisa berubah. Kalau JSON lengkap disimpan, perubahan renderer jauh lebih aman.

3. **Tetap simpan kolom metadata penting.**
   Metadata seperti `request_id`, `ticker`, `market`, `decision`, dan `created_at` tetap perlu dibuat sebagai kolom agar query history cepat dan sederhana.

4. **Pisahkan cache dan history.**
   `SQLiteTTLCache` tetap untuk cache TTL. Database analysis history dibuat sebagai module baru, misalnya `backend/services/analysis_repository.py`.

5. **Mock data jangan dipindah total ke database.**
   Mock tetap perlu ada di frontend untuk debug tanpa backend/LLM/API. Tetapi struktur mock harus 1:1 dengan result asli yang disimpan ke database.

## Schema SQLite

Gunakan satu tabel utama untuk hasil analisis final.

```sql
CREATE TABLE IF NOT EXISTS analyses (
    request_id TEXT PRIMARY KEY,
    job_id TEXT,
    ticker TEXT NOT NULL,
    market TEXT,
    trade_date TEXT,
    time_horizon_months INTEGER,
    analysis_depth TEXT,
    response_detail TEXT,
    decision TEXT,
    recommendation TEXT,
    current_price REAL,
    entry_price REAL,
    stop_loss REAL,
    take_profit REAL,
    rr_ratio TEXT,
    source_summary TEXT,
    status TEXT NOT NULL DEFAULT 'completed',
    result_json TEXT NOT NULL,
    request_json TEXT,
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL,
    exported_html_at TEXT,
    exported_pdf_at TEXT
);

CREATE INDEX IF NOT EXISTS idx_analyses_created_at
    ON analyses (created_at DESC);

CREATE INDEX IF NOT EXISTS idx_analyses_ticker_created_at
    ON analyses (ticker, created_at DESC);

CREATE INDEX IF NOT EXISTS idx_analyses_market_created_at
    ON analyses (market, created_at DESC);
```

### Alasan schema

| Kolom | Alasan |
|---|---|
| `request_id` | Kunci utama untuk membuka detail, preview HTML, dan PDF |
| `job_id` | Menjembatani job API lama jika diperlukan |
| `ticker` | Filter recent analysis per saham |
| `market` | Menjaga validasi US/ID dan mencegah global stock legacy masuk report |
| `trade_date` | Menjelaskan tanggal market data yang dianalisis |
| `decision` / `recommendation` | Dipakai untuk daftar history tanpa parse JSON besar |
| `current_price`, `entry_price`, `stop_loss`, `take_profit`, `rr_ratio` | Metadata ringkas untuk display history |
| `result_json` | Sumber kebenaran lengkap untuk UI/report |
| `request_json` | Audit input analisis |
| `created_at` / `updated_at` | Sorting dan audit |
| `exported_html_at` / `exported_pdf_at` | Opsional untuk audit export |

Contoh implementasi awal:

```python
from __future__ import annotations

import json
import sqlite3
import threading
from datetime import datetime, timezone
from pathlib import Path
from typing import Any


def utc_now_iso() -> str:
    return datetime.now(timezone.utc).isoformat()


class AnalysisRepository:
    def __init__(self, db_path: str, max_rows: int = 1000) -> None:
        self.db_path = Path(db_path)
        self.max_rows = max(1, int(max_rows))
        self.db_path.parent.mkdir(parents=True, exist_ok=True)
        self._lock = threading.RLock()
        self._ensure_schema()

    def _connect(self) -> sqlite3.Connection:
        conn = sqlite3.connect(self.db_path, timeout=30)
        conn.row_factory = sqlite3.Row
        conn.execute("PRAGMA busy_timeout = 30000")
        conn.execute("PRAGMA foreign_keys = ON")
        return conn

    def _ensure_schema(self) -> None:
        with self._lock, self._connect() as conn:
            conn.execute("PRAGMA journal_mode = WAL")
            conn.execute(
                """
                CREATE TABLE IF NOT EXISTS analyses (
                    request_id TEXT PRIMARY KEY,
                    job_id TEXT,
                    ticker TEXT NOT NULL,
                    market TEXT,
                    trade_date TEXT,
                    time_horizon_months INTEGER,
                    analysis_depth TEXT,
                    response_detail TEXT,
                    decision TEXT,
                    recommendation TEXT,
                    current_price REAL,
                    entry_price REAL,
                    stop_loss REAL,
                    take_profit REAL,
                    rr_ratio TEXT,
                    source_summary TEXT,
                    status TEXT NOT NULL DEFAULT 'completed',
                    result_json TEXT NOT NULL,
                    request_json TEXT,
                    created_at TEXT NOT NULL,
                    updated_at TEXT NOT NULL,
                    exported_html_at TEXT,
                    exported_pdf_at TEXT
                )
                """
            )
            conn.execute("CREATE INDEX IF NOT EXISTS idx_analyses_created_at ON analyses (created_at DESC)")
            conn.execute("CREATE INDEX IF NOT EXISTS idx_analyses_ticker_created_at ON analyses (ticker, created_at DESC)")
            conn.execute("CREATE INDEX IF NOT EXISTS idx_analyses_market_created_at ON analyses (market, created_at DESC)")

    def save_analysis(
        self,
        *,
        result: dict[str, Any],
        request_payload: dict[str, Any] | None = None,
        job_id: str | None = None,
    ) -> None:
        request_id = str(result.get("request_id") or "").strip()
        ticker = str(result.get("ticker") or "").strip().upper()
        if not request_id or not ticker:
            return

        now = utc_now_iso()
        created_at = str(result.get("analysis_created_at") or result.get("created_at") or now)
        decision = result.get("decision") or result.get("recommendation")

        values = {
            "request_id": request_id,
            "job_id": job_id,
            "ticker": ticker,
            "market": result.get("market"),
            "trade_date": result.get("trade_date"),
            "time_horizon_months": result.get("time_horizon_months"),
            "analysis_depth": result.get("analysis_depth"),
            "response_detail": result.get("response_detail"),
            "decision": decision,
            "recommendation": result.get("recommendation") or decision,
            "current_price": result.get("current_price"),
            "entry_price": result.get("entry_price") or result.get("entry"),
            "stop_loss": result.get("stop_loss"),
            "take_profit": result.get("take_profit"),
            "rr_ratio": result.get("rr_ratio"),
            "source_summary": result.get("source") or result.get("data_source"),
            "status": "completed",
            "result_json": json.dumps(result, ensure_ascii=False, separators=(",", ":")),
            "request_json": json.dumps(request_payload or {}, ensure_ascii=False, separators=(",", ":")),
            "created_at": created_at,
            "updated_at": now,
        }

        with self._lock, self._connect() as conn:
            conn.execute(
                """
                INSERT INTO analyses (
                    request_id, job_id, ticker, market, trade_date,
                    time_horizon_months, analysis_depth, response_detail,
                    decision, recommendation, current_price, entry_price,
                    stop_loss, take_profit, rr_ratio, source_summary,
                    status, result_json, request_json, created_at, updated_at
                ) VALUES (
                    :request_id, :job_id, :ticker, :market, :trade_date,
                    :time_horizon_months, :analysis_depth, :response_detail,
                    :decision, :recommendation, :current_price, :entry_price,
                    :stop_loss, :take_profit, :rr_ratio, :source_summary,
                    :status, :result_json, :request_json, :created_at, :updated_at
                )
                ON CONFLICT(request_id) DO UPDATE SET
                    job_id = excluded.job_id,
                    ticker = excluded.ticker,
                    market = excluded.market,
                    trade_date = excluded.trade_date,
                    time_horizon_months = excluded.time_horizon_months,
                    analysis_depth = excluded.analysis_depth,
                    response_detail = excluded.response_detail,
                    decision = excluded.decision,
                    recommendation = excluded.recommendation,
                    current_price = excluded.current_price,
                    entry_price = excluded.entry_price,
                    stop_loss = excluded.stop_loss,
                    take_profit = excluded.take_profit,
                    rr_ratio = excluded.rr_ratio,
                    source_summary = excluded.source_summary,
                    status = excluded.status,
                    result_json = excluded.result_json,
                    request_json = excluded.request_json,
                    updated_at = excluded.updated_at
                """,
                values,
            )
            self._evict_old_rows(conn)

    def get_analysis(self, request_id: str) -> dict[str, Any] | None:
        with self._lock, self._connect() as conn:
            row = conn.execute(
                "SELECT result_json FROM analyses WHERE request_id = ?",
                (request_id,),
            ).fetchone()
        if row is None:
            return None
        try:
            return json.loads(row["result_json"])
        except json.JSONDecodeError:
            return None

    def list_analyses(self, *, ticker: str | None = None, limit: int = 25) -> list[dict[str, Any]]:
        safe_limit = max(1, min(int(limit), 100))
        params: list[Any] = []
        where = ""
        if ticker:
            where = "WHERE ticker = ?"
            params.append(ticker.strip().upper())

        params.append(safe_limit)
        with self._lock, self._connect() as conn:
            rows = conn.execute(
                f"""
                SELECT
                    request_id, job_id, ticker, market, trade_date,
                    time_horizon_months, analysis_depth, response_detail,
                    decision, recommendation, current_price, entry_price,
                    stop_loss, take_profit, rr_ratio, source_summary,
                    status, created_at, updated_at
                FROM analyses
                {where}
                ORDER BY created_at DESC
                LIMIT ?
                """,
                params,
            ).fetchall()
        return [dict(row) for row in rows]

    def delete_analysis(self, request_id: str) -> bool:
        with self._lock, self._connect() as conn:
            cursor = conn.execute("DELETE FROM analyses WHERE request_id = ?", (request_id,))
            return cursor.rowcount > 0

    def mark_exported(self, request_id: str, export_type: str) -> None:
        if export_type not in {"html", "pdf"}:
            return
        column = "exported_html_at" if export_type == "html" else "exported_pdf_at"
        with self._lock, self._connect() as conn:
            conn.execute(
                f"UPDATE analyses SET {column} = ?, updated_at = ? WHERE request_id = ?",
                (utc_now_iso(), utc_now_iso(), request_id),
            )

    def _evict_old_rows(self, conn: sqlite3.Connection) -> None:
        rows = conn.execute(
            "SELECT request_id FROM analyses ORDER BY created_at DESC LIMIT -1 OFFSET ?",
            (self.max_rows,),
        ).fetchall()
        if rows:
            conn.executemany(
                "DELETE FROM analyses WHERE request_id = ?",
                [(row["request_id"],) for row in rows],
            )
```

## Integrasi saat analisis selesai

### Endpoint non-stream `/analyze`

Di `backend/routes/analysis.py`, setelah `_execute_analysis()` menghasilkan payload final, simpan ke repository.

Contoh pola:

```python
from services.analysis_repository import get_analysis_repository


async def _save_analysis_result_async(result: dict, req: AnalysisRequest, job_id: str | None = None) -> None:
    if not isinstance(result, dict) or result.get("error"):
        return
    repository = get_analysis_repository()
    await asyncio.to_thread(
        repository.save_analysis,
        result=result,
        request_payload=req.model_dump(),
        job_id=job_id,
    )
```

Lalu di `_execute_analysis`:

```python
fields = await _get_or_start_analysis(req, factory, use_cache=use_cache)
payload = _response_payload(request_id, req, fields)
await _save_analysis_result_async(payload, req)
return payload
```

### Job-based analysis `/analysis/jobs`

Di `backend/routes/jobs.py`, pada `start_job()`, setelah `job.complete(...)`, simpan result ke database.

Agar tidak membuat dependency melingkar, paling bersih: `job.complete()` tetap seperti sekarang, lalu di route/helper yang memanggil `start_job` ditambahkan callback optional. Alternatif sederhana: import repository di `jobs.py`. Karena project ini personal/dev, import langsung masih bisa diterima, tetapi callback lebih bersih.

Rekomendasi clean:

```python
async def start_job(..., save_completed_result_func: Callable[..., Awaitable[None]] | None = None):
    ...
    result = response_payload_func(job.request_id, req, fields)
    await job.complete(result)
    if save_completed_result_func is not None:
        await save_completed_result_func(result, req, job.id)
```

Lalu dari `routes/analysis.py` kirim callback `_save_analysis_result_async`.

## Endpoint history baru

Buat file:

```text
backend/routes/analysis_history.py
```

Endpoint yang disarankan:

| Method | Path | Fungsi |
|---|---|---|
| `GET` | `/api/analysis/history` | Ambil daftar recent analyses dari database |
| `GET` | `/api/analysis/history/{request_id}` | Ambil detail result lengkap dari database |
| `DELETE` | `/api/analysis/history/{request_id}` | Hapus satu history result |

Contoh route:

```python
from __future__ import annotations

import asyncio

from fastapi import APIRouter, Query, Request

from config import ANALYSIS_HISTORY_DEFAULT_LIMIT
from errors import NotFoundError
from rate_limiter import limit_request, request_policy
from services.analysis_repository import get_analysis_repository

router = APIRouter(tags=["analysis-history"])


@router.get("/analysis/history")
async def list_analysis_history(
    request: Request,
    ticker: str | None = None,
    limit: int = Query(default=ANALYSIS_HISTORY_DEFAULT_LIMIT, ge=1, le=100),
):
    async with limit_request(request, request_policy()):
        repository = get_analysis_repository()
        items = await asyncio.to_thread(repository.list_analyses, ticker=ticker, limit=limit)
        return {"items": items}


@router.get("/analysis/history/{request_id}")
async def get_analysis_history_result(request_id: str, request: Request):
    async with limit_request(request, request_policy()):
        repository = get_analysis_repository()
        result = await asyncio.to_thread(repository.get_analysis, request_id)
        if result is None:
            raise NotFoundError("Analysis result was not found.", details={"request_id": request_id})
        return result


@router.delete("/analysis/history/{request_id}")
async def delete_analysis_history_result(request_id: str, request: Request):
    async with limit_request(request, request_policy()):
        repository = get_analysis_repository()
        deleted = await asyncio.to_thread(repository.delete_analysis, request_id)
        if not deleted:
            raise NotFoundError("Analysis result was not found.", details={"request_id": request_id})
        return {"deleted": True, "request_id": request_id}
```

Daftarkan router di `backend/main.py`:

```python
from routes import analysis_history

```

    """Return a completed analysis payload by request_id without rerunning analysis."""

    job = await jobs.JOB_STORE.get_by_request_id(request_id)

```javascript
import { buildApiUrl, buildAuthHeaders, readHttpError } from './api';

export async function fetchAnalysisHistory({ ticker = '', limit = 25 } = {}) {
  const params = new URLSearchParams();
  if (ticker) params.set('ticker', ticker);
  params.set('limit', String(limit));

  const response = await fetch(buildApiUrl(`/analysis/history?${params.toString()}`), {
    headers: {
      ...buildAuthHeaders(),
      Accept: 'application/json',
    },
  });

  if (!response.ok) throw new Error(await readHttpError(response));
  const payload = await response.json();
  return Array.isArray(payload.items) ? payload.items : [];
}

export async function fetchAnalysisHistoryResult(requestId) {
  const response = await fetch(buildApiUrl(`/analysis/history/${encodeURIComponent(requestId)}`), {
    headers: {
      ...buildAuthHeaders(),
      Accept: 'application/json',
    },
  });

  if (!response.ok) throw new Error(await readHttpError(response));
  return response.json();
}

export async function deleteAnalysisHistoryResult(requestId) {
  const response = await fetch(buildApiUrl(`/analysis/history/${encodeURIComponent(requestId)}`), {
    method: 'DELETE',
    headers: buildAuthHeaders(),
  });

  if (!response.ok) throw new Error(await readHttpError(response));
  return response.json();
}
```

```python
@router.get("/analysis/{request_id}")
async def get_analysis_result_by_request_id(request_id: str, request: Request):
    async with limit_request(request, request_policy()):
        job = await _JOB_STORE.get_by_request_id(request_id)
        if job is not None:
            if job.result is not None:
                return job.result
            return job.public_summary()

        repository = get_analysis_repository()

        if result is not None:
            return result

        raise _analysis_result_not_found(request_id)
```

GET /api/analysis/history/{request_id}

Rekomendasi: **Pilihan A + endpoint baru tetap ada**. Dengan begitu route lama tetap kompatibel, sementara endpoint history tetap jelas untuk daftar/hapus history.

## Migration strategy

Karena ini project personal/dev, migration bisa dibuat sederhana dulu:

1. Repository menjalankan `CREATE TABLE IF NOT EXISTS` saat startup/first use.
2. Index dibuat otomatis.
3. Jika schema berubah besar, buat function `_ensure_migrations()` dengan `PRAGMA user_version`.

Contoh migration version sederhana:

```python
version = conn.execute("PRAGMA user_version").fetchone()[0]
if version < 1:
    # create base tables
    conn.execute("PRAGMA user_version = 1")
```

Untuk sekarang, `CREATE TABLE IF NOT EXISTS` cukup. Jangan langsung menarik Alembic ke project personal kecuali benar-benar butuh. Kadang manusia memasang sistem migrasi enterprise untuk tiga tabel, lalu bertanya kenapa hidup terasa berat.

## Risiko dan mitigasi

| Risiko | Penyebab | Mitigasi |
|---|---|---|
| Database terkunci | SQLite write bersamaan | Pakai `threading.RLock`, `busy_timeout`, WAL mode, dan operasi write singkat |
| Response analisis gagal karena DB error | Save dilakukan inline tanpa guard | Bungkus save DB dengan `try/except`, log error saja |
| History terlalu besar | Semua result JSON disimpan terus | Batasi `ANALYSIS_HISTORY_MAX_ROWS` |
| Schema berubah | Field result berubah seiring UI | Simpan full `result_json`, metadata hanya untuk query/list |
| Report gagal untuk result lama | Contract lama tidak lengkap | `build_report_context()` harus punya fallback aman untuk field optional |
| Mock berbeda dari result asli | Mock dibuat manual tanpa contract | Buat mock berdasarkan `analysisContract.js` dan snapshot test |

## Catatan penting tentang data finansial

Database ini menyimpan **hasil analisis saat itu**, bukan data market realtime. Jadi hasil lama harus dianggap snapshot historis dari proses analisis, bukan rekomendasi live.

Untuk UI/export, tampilkan metadata seperti:

```text
Analysis created at: 2026-05-28T08:00:00Z
Trade date: 2026-05-28
Data source: yfinance / Alpha Vantage / Finnhub
```

Ini penting agar user tidak melihat PDF lama lalu mengira itu masih berlaku untuk market sekarang. Market berubah, sayangnya tidak meminta izin dulu kepada UI kamu.
