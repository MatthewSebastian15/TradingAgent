**Kontrak Owner Session**

| Item | Keputusan |
|---|---|
| Shared proxy credential | Nginx tetap mengirim `x-api-key`. Backend memakainya hanya untuk autentikasi service. Nilai ini tidak boleh menjadi `owner_id` atau key kuota pengguna. |
| Bootstrap owner | Frontend memanggil `POST /api/session` sebelum request API lain. Backend menerbitkan signed token dengan owner ID acak dan expiry. |
| Header browser | Frontend mengirim token melalui `x-owner-token`. Frontend menyimpan token di `sessionStorage`, bukan `localStorage`. |
| Validasi backend | Backend memverifikasi signature dan expiry sebelum menerima token. Backend memakai hash owner ID dari token sebagai scope job, result, report, stream, cancel, dan rate limit. |
| Production | Resource endpoint menolak request tanpa signed owner token. `x-session-id` lama tidak menjadi owner pada production. |
| Development | Mode development dapat melakukan bootstrap token tanpa konfigurasi deployment tambahan. |
| Environment | Tambahkan `OWNER_SESSION_SECRET` dan `OWNER_SESSION_TTL_SECONDS`. `OWNER_SESSION_SECRET` wajib pada production. Default TTL mengikuti `ANALYSIS_JOB_TTL_SECONDS`. |

**Kontrak Resource ID**

| Resource | Endpoint canonical | Locator |
|---|---|---|
| Buat job | `POST /api/analysis/jobs` | Backend mengembalikan `job_id` dan `request_id` |
| Status dan result | `GET /api/analysis/jobs/{job_id}` | `job_id` |
| Stream | `GET /api/analysis/jobs/{job_id}/events` | `job_id` |
| Cancel | `DELETE /api/analysis/jobs/{job_id}` | `job_id` |
| Report HTML | `GET /api/analysis/jobs/{job_id}/report.html` | `job_id` |
| Report PDF | `GET /api/analysis/jobs/{job_id}/report.pdf` | `job_id` |
| Direct URL frontend | `/analysis/{job_id}` | `job_id` |
| Trace log | Header dan response `x-request-id` | `request_id`, bukan locator resource |

`GET /api/analysis/{request_id}` dan alias report berbasis `request_id` tetap tersedia hanya selama satu siklus migrasi. Semua alias wajib memeriksa owner. Hapus alias setelah frontend dan dokumentasi memakai `job_id`.

**Schema History Browser Versi 2**

```json
{
  "schema_version": 2,
  "job_id": "backend-generated-uuid",
  "request_id": "trace-id",
  "ticker": "BBCA.JK",
  "market": "ID",
  "trade_date": "2026-06-01",
  "status": "completed",

  "analysis_created_at": "2026-06-01T12:00:00Z",

```

Aturan migrasi:

- Simpan hanya array ringkasan versi 2 pada `ta_analysis_history` dan `ta_analysis_mock_history`.
- Hapus key payload lama dengan pola `{historyKey}:result:*` saat migrasi dan saat pengguna memilih clear history.
- Bersihkan field lama yang tidak ada pada schema versi 2.
- Ambil payload result dari backend memakai `job_id` saat direct URL atau reload browser dibuka.
- Pertahankan payload result aktif hanya pada state memori halaman.
- Jangan simpan `position_quantity`, `average_entry_price`, laporan agent lengkap, raw state, atau debug payload ke `localStorage`.
- Tunda fitur opt-in payload penuh sampai ada kebutuhan produk dan desain consent yang eksplisit.
