## 1. Filosofi dan Batasan Backtest Ini

### Apa yang ditest

Backtest ini mengukur seberapa akurat sinyal BUY/HOLD/SELL dari AI agent kamu
jika dieksekusi secara mekanis dengan aturan entry/exit yang sudah didefinisikan sebelumnya.

### Apa yang TIDAK ditest

- Kemampuan timing market secara real-time
- Likuiditas eksekusi (slippage, spread)
- Pengaruh berita mendadak setelah sinyal dibuat
- Performa broker sesungguhnya

### Prinsip isolasi

Folder backtest berdiri sendiri. Ia mengimpor pipeline dari codebase utama sebagai
dependensi eksternal (seperti library), bukan memodifikasinya. Kamu bisa hapus seluruh
folder backtest tanpa merusak satu pun file di main project.

## 3. Definisi Aturan Trading

Sebelum run apapun, aturan ini harus dikunci. Backtest tidak bermakna tanpa aturan yang konsisten.

### 3.1 Universe Saham

Universe backtest dikunci ke **5 saham IDX** berikut. Semua ticker harus menggunakan format Yahoo Finance dengan suffix `.JK`, karena `yfinance` membaca saham Indonesia menggunakan format tersebut. Jangan gunakan ticker polos seperti `BBCA`, `BBRI`, `TLKM`, `BREN`, atau `TPIA` di dalam kode backtest, karena itu bisa membuat data tidak ditemukan atau malah terbaca sebagai instrumen lain. Ya, satu suffix kecil bisa mengacaukan eksperimen satu proyek. Klasik.

| Ticker Input User | Ticker Yahoo Finance | Nama Saham                     | Sektor Utama                         | Catatan Backtest |
|-------------------|----------------------|--------------------------------|--------------------------------------|------------------|
| BBCA              | BBCA.JK              | Bank Central Asia Tbk          | Perbankan                            | Ticker besar dan likuid, cocok sebagai baseline bank besar. |
| BBRI              | BBRI.JK              | Bank Rakyat Indonesia Tbk      | Perbankan                            | Ticker bank besar dengan karakter bisnis ritel/mikro. |
| TLKM              | TLKM.JK              | Telkom Indonesia Tbk           | Telekomunikasi / Infrastruktur Digital| Menggantikan `BMRI.JK` agar universe tidak terlalu berat di sektor bank. |
| BREN              | BREN.JK              | Barito Renewables Energy Tbk   | Energi Terbarukan                    | Perlu start-date override karena listing lebih baru dibanding ticker lain. |
| TPIA              | TPIA.JK              | Chandra Asri Pacific Tbk       | Petrokimia                           | Ticker non-bank untuk variasi siklus industri. |

Aturan konsistensi ticker:

- **Input manusia** boleh ditulis sebagai `BBCA`, `BBRI`, `TLKM`, `BREN`, `TPIA`.
- **Kode backtest** wajib memakai `BBCA.JK`, `BBRI.JK`, `TLKM.JK`, `BREN.JK`, `TPIA.JK`.
- **Dokumen ini tidak lagi memakai `BMRI.JK`** sebagai bagian dari universe backtest.
- Semua output CSV, JSON, cache SQLite, log, dan report harus tetap menyimpan ticker dalam format Yahoo Finance agar mudah ditelusuri ulang.

### 3.2 Periode Backtest

- Mulai: 1 Januari 2023
- Selesai: 31 Desember 2024
- Total: 24 bulan data
- Frekuensi sinyal: bulanan (1 sinyal per ticker per bulan = 24 sinyal potensial)
- Dari 24, ambil 50 trade? Tidak cukup. Solusi: gunakan sinyal mingguan (sekitar 96 sinyal per ticker per 2 tahun), lalu ambil 50 yang valid.

### 3.3 Frekuensi Sinyal

Gunakan sinyal **mingguan** untuk mendapatkan 50 trade per ticker:
- 2 tahun x 52 minggu = 104 minggu
- Hanya sinyal BUY yang dieksekusi sebagai trade (bukan HOLD atau SELL)
- Target: cukup sinyal BUY untuk mencapai 50 trade per ticker

Jika sinyal BUY kurang dari 50 dalam 2 tahun, extend periode ke 2022 atau perlonggar filter.

### 3.4 Aturan Entry

- **Kapan masuk**: Open price hari Senin setelah sinyal dihasilkan pada hari Jumat
- **Trigger**: Hanya sinyal BUY yang menghasilkan trade
- **Sinyal HOLD/SELL**: dilewati, tidak ada posisi dibuka

### 3.5 Aturan Exit (pilih salah satu, kunci sebelum run)

Rekomendasi untuk test pertama: gunakan Exit Rule A.

**Exit Rule A — Fixed Time Horizon (paling clean untuk test pertama)**
- Keluar di close price setelah 4 minggu (20 hari trading)
- Tidak ada SL atau TP
- Hasil: murni mengukur apakah arah prediksi AI agent benar

**Exit Rule B — SL/TP dari output agent**
- Gunakan stop_loss dan take_profit dari JSON output agent
- Keluar saat SL atau TP tercapai pertama kali (daily close)
- Fallback: keluar paksa setelah 8 minggu jika tidak ada yang kena

**Exit Rule C — Hybrid**
- SL: -5% dari entry (jika agent tidak berikan SL)
- TP: +10% dari entry (jika agent tidak berikan TP)
- Max hold: 6 minggu

### 3.6 Definisi WIN dan LOSS

- WIN: return positif saat exit
- LOSS: return negatif saat exit
- BREAKEVEN (|return| < 0.5%): tidak dihitung, diulang dengan sinyal berikutnya

### 3.7 Metrik yang Diukur

| Metrik              | Formula                              |
|---------------------|--------------------------------------|
| Winrate             | Jumlah WIN / Total Trade             |
| Average Win         | Rata-rata return trade WIN           |
| Average Loss        | Rata-rata return trade LOSS          |
| Profit Factor       | Total gain WIN / Total loss LOSS     |
| Max Drawdown        | Penurunan equity terbesar berurutan  |
| Expectancy per Trade| (Winrate x AvgWin) - (Lossrate x AvgLoss) |
| Total Return        | Sum semua return, flat sizing        |
| Sharpe Ratio        | Return / StdDev return, annualized   |

## 4. Rencana 50 Trade per Ticker

### Distribusi 50 Trade

```
Periode: Jan 2023 - Des 2024 (24 bulan, ~96 minggu)
Target: 50 sinyal BUY per ticker

Ekspektasi sinyal BUY: sekitar 30-60% dari total sinyal
Jika rata-rata BUY = 40% → 96 x 40% = 38 sinyal BUY
Jika kurang dari 50: extend ke 2022 sampai quota terpenuhi

Fallback: jika extend tetap kurang, turunkan target ke 30 trade
dan dokumentasikan kenapa (market bearish sepanjang periode)
```

### Jadwal Pengambilan Sinyal

```
Setiap Jumat sore, agent menganalisis ticker
Senin pagi entry dilakukan jika sinyal = BUY
Sinyal diambil mundur (historical), bukan live
```

### Cara Menentukan 50 Trade

Di `config.py`, set:

```python
TARGET_TRADES_PER_TICKER = 50
SIGNAL_FREQUENCY = "weekly"       # ambil sinyal tiap minggu
BACKTEST_START = "2022-01-03"     # mulai dari 2022 untuk buffer
BACKTEST_END   = "2024-12-31"
ENTRY_SIGNAL   = "BUY"            # hanya BUY yang jadi trade
```

Runner akan berhenti mengambil sinyal baru setelah 50 BUY terkumpul per ticker.

## 7. Kode: signal_generator.py

```python
# backtest/signal_generator.py
# Bertanggung jawab:
# 1. Generate daftar tanggal sinyal (mingguan/bulanan)
# 2. Cek cache SQLite dulu sebelum call LLM
# 3. Jika cache miss, panggil pipeline dari main project
# 4. Simpan hasil ke cache
# 5. Return sinyal untuk diproses simulator

import sqlite3
import json
import time
import logging
from datetime import datetime, timedelta
from typing import Optional
import pandas as pd

import config

logger = logging.getLogger(__name__)


# ─── Cache Setup ─────────────────────────────────────────────────

def init_cache_db():
    """Buat tabel cache jika belum ada."""
    conn = sqlite3.connect(config.CACHE_DB)
    conn.execute("""
        CREATE TABLE IF NOT EXISTS signals (
            id           INTEGER PRIMARY KEY AUTOINCREMENT,
            ticker       TEXT NOT NULL,
            signal_date  TEXT NOT NULL,
            action       TEXT,
            confidence   REAL,
            entry_price  REAL,
            stop_loss    REAL,
            take_profit  REAL,
            reasoning    TEXT,
            raw_json     TEXT,
            created_at   TEXT DEFAULT (datetime('now')),
            UNIQUE(ticker, signal_date)
        )
    """)
    conn.commit()
    conn.close()
    logger.info(f"Cache DB siap di: {config.CACHE_DB}")


def get_cached_signal(ticker: str, signal_date: str) -> Optional[dict]:
    """Ambil sinyal dari cache. Return None jika tidak ada."""
    conn = sqlite3.connect(config.CACHE_DB)
    row = conn.execute(
        "SELECT * FROM signals WHERE ticker=? AND signal_date=?",
        (ticker, signal_date)
    ).fetchone()
    conn.close()
    if row:
        cols = ["id", "ticker", "signal_date", "action", "confidence",
                "entry_price", "stop_loss", "take_profit", "reasoning",
                "raw_json", "created_at"]
        return dict(zip(cols, row))
    return None


def save_signal_to_cache(ticker: str, signal_date: str, signal_data: dict):
    """Simpan sinyal ke cache."""
    conn = sqlite3.connect(config.CACHE_DB)
    conn.execute("""
        INSERT OR REPLACE INTO signals
        (ticker, signal_date, action, confidence, entry_price, stop_loss,
         take_profit, reasoning, raw_json)
        VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?)
    """, (
        ticker,
        signal_date,
        signal_data.get("action", "UNKNOWN"),
        signal_data.get("confidence", 0.0),
        signal_data.get("entry_price"),
        signal_data.get("stop_loss"),
        signal_data.get("take_profit"),
        signal_data.get("reasoning", ""),
        json.dumps(signal_data),
    ))
    conn.commit()
    conn.close()


# ─── Date Generator ──────────────────────────────────────────────

def generate_signal_dates(start: str, end: str, frequency: str) -> list[str]:
    """
    Generate list tanggal untuk pengambilan sinyal.
    Frequency: 'weekly' = setiap Jumat, 'monthly' = hari pertama tiap bulan.
    """
    dates = []
    current = datetime.strptime(start, "%Y-%m-%d")
    end_dt  = datetime.strptime(end, "%Y-%m-%d")

    if frequency == "weekly":
        # Maju ke Jumat pertama
        while current.weekday() != 4:  # 4 = Jumat
            current += timedelta(days=1)
        while current <= end_dt:
            dates.append(current.strftime("%Y-%m-%d"))
            current += timedelta(weeks=1)
    elif frequency == "monthly":
        while current <= end_dt:
            dates.append(current.strftime("%Y-%m-%d"))
            if current.month == 12:
                current = current.replace(year=current.year+1, month=1)
            else:
                current = current.replace(month=current.month+1)

    return dates


# ─── Pipeline Caller ─────────────────────────────────────────────

def call_pipeline(ticker: str, analysis_date: str) -> dict:
    """
    Panggil pipeline dari main project.
    Ini satu-satunya titik kontak dengan codebase utama.
    Semua import terjadi di sini agar terisolasi.
    """
    try:
        # Import pipeline dari main project
        # Pipeline dipanggil sebagai library, bukan dimodifikasi
        from tradingagents.pipeline_balanced import run_analysis

        logger.info(f"Memanggil pipeline: {ticker} @ {analysis_date}")

        result = run_analysis(
            ticker=ticker,
            analysis_date=analysis_date,
            llm_provider=config.LLM_PROVIDER,
            llm_model=config.LLM_MODEL,
            max_debate_rounds=1,   # minimal untuk hemat biaya
        )

        # Normalize output ke format backtest
        # Sesuaikan key ini dengan actual output pipeline kamu
        signal = {
            "action":      result.get("recommendation", "HOLD").upper(),
            "confidence":  result.get("confidence_score", 0.5),
            "entry_price": result.get("entry_price"),
            "stop_loss":   result.get("stop_loss"),
            "take_profit": result.get("take_profit"),
            "reasoning":   result.get("executive_summary", ""),
        }

        return signal

    except ImportError as e:
        logger.error(f"Gagal import pipeline: {e}")
        logger.error("Pastikan kamu run: pip install -e backend/tradingagents-core")
        raise
    except Exception as e:
        logger.error(f"Pipeline error untuk {ticker} @ {analysis_date}: {e}")
        # Return sinyal netral jika pipeline gagal
        return {
            "action":      "ERROR",
            "confidence":  0.0,
            "entry_price": None,
            "stop_loss":   None,
            "take_profit": None,
            "reasoning":   f"Pipeline error: {str(e)}",
        }


# ─── Main Generator ──────────────────────────────────────────────

def generate_signals_for_ticker(ticker: str) -> list[dict]:
    """
    Generate semua sinyal untuk satu ticker.
    Berhenti setelah TARGET_TRADES_PER_TICKER sinyal BUY terkumpul.
    Return list sinyal lengkap (BUY + HOLD + SELL + ERROR).
    """
    init_cache_db()

    effective_start = config.TICKER_START_OVERRIDE.get(ticker, config.BACKTEST_START)
    all_dates    = generate_signal_dates(
        effective_start, config.BACKTEST_END, config.SIGNAL_FREQUENCY
    )
    signals      = []
    buy_count    = 0
    cache_hits   = 0
    api_calls    = 0

    logger.info(f"\n{'='*60}")
    logger.info(f"Generating sinyal untuk {ticker}")
    logger.info(f"Effective start date: {effective_start}")
    logger.info(f"Total tanggal kandidat: {len(all_dates)}")
    logger.info(f"Target BUY: {config.TARGET_TRADES_PER_TICKER}")

    for date in all_dates:
        if buy_count >= config.TARGET_TRADES_PER_TICKER:
            logger.info(f"Target {config.TARGET_TRADES_PER_TICKER} BUY tercapai. Stop.")
            break

        # Cek cache dulu
        cached = get_cached_signal(ticker, date)

        if cached and not config.FORCE_REGEN:
            signal = json.loads(cached["raw_json"])
            signal["signal_date"] = date
            signal["ticker"]      = ticker
            signal["from_cache"]  = True
            cache_hits += 1
            logger.debug(f"[CACHE] {ticker} {date} → {signal.get('action')}")
        else:
            # Call API
            time.sleep(config.DELAY_SECONDS)   # rate limiting
            signal = call_pipeline(ticker, date)
            signal["signal_date"] = date
            signal["ticker"]      = ticker
            signal["from_cache"]  = False
            save_signal_to_cache(ticker, date, signal)
            api_calls += 1
            logger.info(f"[API]   {ticker} {date} → {signal.get('action')} "
                        f"(conf: {signal.get('confidence', 0):.2f})")

        signals.append(signal)

        if signal.get("action") == config.ENTRY_SIGNAL:
            buy_count += 1

    logger.info(f"\nSelesai {ticker}: {len(signals)} sinyal total, "
                f"{buy_count} BUY, {cache_hits} dari cache, {api_calls} API call")

    return signals


def generate_all_signals() -> dict[str, list[dict]]:
    """Generate sinyal untuk semua ticker. Return dict ticker → list sinyal."""
    all_signals = {}
    for ticker in config.TICKERS:
        all_signals[ticker] = generate_signals_for_ticker(ticker)
    return all_signals
```

```python
# backtest/simulator.py
# Pure Python, ZERO LLM call.
# Ambil sinyal dari generator, fetch OHLCV dari yfinance,
# simulasikan eksekusi tiap trade, hitung hasil.

import logging
from datetime import datetime, timedelta
import pandas as pd
import yfinance as yf
import numpy as np

import config

logger = logging.getLogger(__name__)


# ─── Price Data ──────────────────────────────────────────────────

_price_cache: dict[str, pd.DataFrame] = {}

def get_price_data(ticker: str) -> pd.DataFrame:
    """Fetch OHLCV dari yfinance. Cache in-memory per session."""
    if ticker in _price_cache:
        return _price_cache[ticker]

    logger.info(f"Fetching harga historis: {ticker}")
    df = yf.download(
        ticker,
        start=config.BACKTEST_START,
        end=config.BACKTEST_END,
        auto_adjust=True,
        progress=False,
    )
    if df.empty:
        raise ValueError(f"Tidak ada data harga untuk {ticker}. "
                         f"Cek apakah ticker valid di Yahoo Finance.")
    df.index = pd.to_datetime(df.index)
    _price_cache[ticker] = df
    return df


def get_next_trading_day(df: pd.DataFrame, from_date: str, skip_days: int = 3) -> pd.Timestamp:
    """
    Ambil hari trading berikutnya setelah from_date + skip_days.
    Dipakai untuk simulasi entry: sinyal Jumat → entry Senin.
    """
    target = pd.Timestamp(from_date) + timedelta(days=skip_days)
    available = df.index[df.index >= target]
    if available.empty:
        return None
    return available[0]


def get_price_at(df: pd.DataFrame, date: pd.Timestamp, price_col: str = "Open") -> float:
    """Ambil harga di tanggal tertentu. Cari hari trading terdekat jika tidak ada."""
    if date in df.index:
        return float(df.loc[date, price_col])
    available = df.index[df.index >= date]
    if available.empty:
        return None
    return float(df.loc[available[0], price_col])


# ─── Trade Simulation ─────────────────────────────────────────────

def simulate_trade_rule_a(df: pd.DataFrame, entry_date: pd.Timestamp, entry_price: float) -> dict:
    """
    Exit Rule A: keluar setelah HOLD_WEEKS minggu di close price.
    Paling clean untuk validasi arah prediksi.
    """
    hold_days   = config.HOLD_WEEKS * 7
    target_exit = entry_date + timedelta(days=hold_days)
    exit_dates  = df.index[df.index >= target_exit]

    if exit_dates.empty:
        return {"exit_date": None, "exit_price": None, "exit_reason": "NO_DATA"}

    exit_date  = exit_dates[0]
    exit_price = float(df.loc[exit_date, "Close"])
    ret        = (exit_price - entry_price) / entry_price

    return {
        "exit_date":   exit_date.strftime("%Y-%m-%d"),
        "exit_price":  exit_price,
        "return_pct":  ret,
        "exit_reason": f"TIME_EXIT_{config.HOLD_WEEKS}W",
    }


def simulate_trade_rule_b(df: pd.DataFrame, entry_date: pd.Timestamp,
                           entry_price: float, stop_loss: float,
                           take_profit: float) -> dict:
    """
    Exit Rule B: gunakan SL/TP dari output agent.
    Cek daily close, mana yang kena duluan.
    """
    sl = stop_loss    or entry_price * (1 + config.DEFAULT_SL_PCT)
    tp = take_profit  or entry_price * (1 + config.DEFAULT_TP_PCT)
    max_date = entry_date + timedelta(weeks=config.MAX_HOLD_WEEKS)

    future = df[df.index > entry_date]

    for date, row in future.iterrows():
        close = float(row["Close"])
        ret   = (close - entry_price) / entry_price

        if close <= sl:
            return {"exit_date": date.strftime("%Y-%m-%d"), "exit_price": close,
                    "return_pct": ret, "exit_reason": "SL_HIT"}
        if close >= tp:
            return {"exit_date": date.strftime("%Y-%m-%d"), "exit_price": close,
                    "return_pct": ret, "exit_reason": "TP_HIT"}
        if date >= max_date:
            return {"exit_date": date.strftime("%Y-%m-%d"), "exit_price": close,
                    "return_pct": ret, "exit_reason": "MAX_HOLD"}

    return {"exit_date": None, "exit_price": None, "return_pct": 0,
            "exit_reason": "NO_EXIT_FOUND"}


def simulate_trade_rule_c(df: pd.DataFrame, entry_date: pd.Timestamp,
                           entry_price: float, stop_loss: float,
                           take_profit: float) -> dict:
    """Exit Rule C: hybrid, SL/TP dengan default jika agent tidak berikan nilai."""
    return simulate_trade_rule_b(df, entry_date, entry_price, stop_loss, take_profit)


# ─── Simulator Utama ─────────────────────────────────────────────

def simulate_ticker(ticker: str, signals: list[dict]) -> list[dict]:
    """
    Simulasikan semua trade untuk satu ticker.
    Return list trade result.
    """
    df     = get_price_data(ticker)
    trades = []
    trade_num = 0

    buy_signals = [s for s in signals if s.get("action") == config.ENTRY_SIGNAL]
    logger.info(f"\nSimulasi {ticker}: {len(buy_signals)} sinyal BUY")

    for signal in buy_signals:
        if trade_num >= config.TARGET_TRADES_PER_TICKER:
            break

        signal_date  = signal["signal_date"]
        entry_date   = get_next_trading_day(df, signal_date, skip_days=3)

        if entry_date is None:
            logger.warning(f"Tidak ada hari trading setelah {signal_date}, skip.")
            continue

        entry_price = get_price_at(df, entry_date, "Open")
        if entry_price is None or entry_price <= 0:
            logger.warning(f"Harga entry tidak valid di {entry_date}, skip.")
            continue

        # Simulasi exit berdasarkan rule yang dipilih
        if config.EXIT_RULE == "A":
            result = simulate_trade_rule_a(df, entry_date, entry_price)
        elif config.EXIT_RULE == "B":
            result = simulate_trade_rule_b(
                df, entry_date, entry_price,
                signal.get("stop_loss"), signal.get("take_profit")
            )
        else:  # C
            result = simulate_trade_rule_c(
                df, entry_date, entry_price,
                signal.get("stop_loss"), signal.get("take_profit")
            )

        if result["exit_date"] is None:
            continue

        ret = result["return_pct"]

        # Tentukan outcome
        if abs(ret) < config.BREAKEVEN_THRESHOLD:
            outcome = "BREAKEVEN"
        elif ret > 0:
            outcome = "WIN"
        else:
            outcome = "LOSS"

        trade = {
            "trade_num":     trade_num + 1,
            "ticker":        ticker,
            "signal_date":   signal_date,
            "entry_date":    entry_date.strftime("%Y-%m-%d"),
            "entry_price":   round(entry_price, 2),
            "exit_date":     result["exit_date"],
            "exit_price":    round(result["exit_price"], 2),
            "return_pct":    round(ret * 100, 2),
            "exit_reason":   result["exit_reason"],
            "outcome":       outcome,
            "confidence":    signal.get("confidence", 0),
            "from_cache":    signal.get("from_cache", False),
        }

        trades.append(trade)
        trade_num += 1

        logger.info(f"  Trade #{trade_num:02d}: {signal_date} → {result['exit_reason']} "
                    f"| {outcome} | {ret*100:+.2f}%")

    return trades


def simulate_all(all_signals: dict[str, list[dict]]) -> dict[str, list[dict]]:
    """Simulasikan semua ticker. Return dict ticker → list trades."""
    all_trades = {}
    for ticker, signals in all_signals.items():
        all_trades[ticker] = simulate_ticker(ticker, signals)
    return all_trades
```

```python
# backtest/report.py
# Hitung metrik dan cetak laporan.
# Tidak ada LLM, tidak ada yfinance. Pure math.

import json
import csv
import os
import logging
from datetime import datetime
import numpy as np
import pandas as pd

import config

logger = logging.getLogger(__name__)


def calculate_metrics(trades: list[dict]) -> dict:
    """Hitung semua metrik untuk satu ticker."""
    if not trades:
        return {"error": "Tidak ada trade"}

    # Filter breakeven dari kalkulasi winrate
    valid = [t for t in trades if t["outcome"] != "BREAKEVEN"]
    wins  = [t for t in valid  if t["outcome"] == "WIN"]
    losses= [t for t in valid  if t["outcome"] == "LOSS"]

    returns     = [t["return_pct"] for t in trades]
    win_returns = [t["return_pct"] for t in wins]
    los_returns = [t["return_pct"] for t in losses]

    total_trade = len(valid)
    winrate     = len(wins)  / total_trade * 100 if total_trade > 0 else 0

    avg_win  = np.mean(win_returns)  if win_returns else 0
    avg_loss = np.mean(los_returns)  if los_returns else 0

    total_gain = sum(win_returns) if win_returns else 0
    total_loss = abs(sum(los_returns)) if los_returns else 0
    profit_factor = total_gain / total_loss if total_loss > 0 else float("inf")

    lossrate    = 1 - (winrate / 100)
    expectancy  = (winrate/100 * avg_win) + (lossrate * avg_loss)

    total_return = sum(returns)

    # Max drawdown (berurutan)
    equity  = np.cumsum(returns)
    peak    = np.maximum.accumulate(equity)
    dd      = equity - peak
    max_dd  = float(np.min(dd)) if len(dd) > 0 else 0

    # Sharpe (simplified, assume risk-free = 0)
    std_ret = np.std(returns) if len(returns) > 1 else 1
    sharpe  = (np.mean(returns) / std_ret * np.sqrt(52)) if std_ret > 0 else 0

    return {
        "total_trade":     len(trades),
        "valid_trade":     total_trade,
        "breakeven":       len(trades) - total_trade,
        "wins":            len(wins),
        "losses":          len(losses),
        "winrate_pct":     round(winrate, 2),
        "avg_win_pct":     round(avg_win, 2),
        "avg_loss_pct":    round(avg_loss, 2),
        "profit_factor":   round(profit_factor, 3),
        "expectancy_pct":  round(expectancy, 2),
        "total_return_pct":round(total_return, 2),
        "max_drawdown_pct":round(max_dd, 2),
        "sharpe_ratio":    round(sharpe, 3),
    }


def print_summary(all_trades: dict[str, list[dict]]):
    """Print ringkasan ke terminal."""
    print("\n" + "="*70)
    print("BACKTEST RESULTS — TradingAgent IDX")
    print(f"Exit Rule: {config.EXIT_RULE} | "
          f"Period: {config.BACKTEST_START} → {config.BACKTEST_END}")
    print("="*70)

    aggregate_returns = []

    for ticker, trades in all_trades.items():
        m = calculate_metrics(trades)
        aggregate_returns.extend([t["return_pct"] for t in trades])

        print(f"\n[ {ticker} ]")
        print(f"  Total Trade     : {m['total_trade']} ({m['valid_trade']} valid, {m['breakeven']} breakeven)")
        print(f"  WIN / LOSS      : {m['wins']} / {m['losses']}")
        print(f"  Winrate         : {m['winrate_pct']}%")
        print(f"  Avg Win         : +{m['avg_win_pct']}%")
        print(f"  Avg Loss        : {m['avg_loss_pct']}%")
        print(f"  Profit Factor   : {m['profit_factor']}")
        print(f"  Expectancy      : {m['expectancy_pct']}% per trade")
        print(f"  Total Return    : {m['total_return_pct']}%  (flat sizing)")
        print(f"  Max Drawdown    : {m['max_drawdown_pct']}%")
        print(f"  Sharpe Ratio    : {m['sharpe_ratio']}")

    # Agregat semua ticker
    if aggregate_returns:
        print("\n" + "-"*70)
        print("AGREGAT (semua ticker, flat sizing)")
        all_wins   = [r for r in aggregate_returns if r > config.BREAKEVEN_THRESHOLD*100]
        all_losses = [r for r in aggregate_returns if r < -config.BREAKEVEN_THRESHOLD*100]
        total = len([r for r in aggregate_returns if abs(r) >= config.BREAKEVEN_THRESHOLD*100])
        wr = len(all_wins)/total*100 if total > 0 else 0
        print(f"  Total Trade     : {len(aggregate_returns)}")
        print(f"  Winrate         : {wr:.2f}%")
        print(f"  Total Return    : {sum(aggregate_returns):.2f}%")
        print(f"  Avg per Trade   : {np.mean(aggregate_returns):.2f}%")

    print("\n" + "="*70)


def save_results(all_trades: dict[str, list[dict]]):
    """Simpan hasil ke CSV dan JSON."""
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")

    # CSV per ticker
    for ticker, trades in all_trades.items():
        safe_ticker = ticker.replace(".", "_")
        csv_path    = os.path.join(config.RESULTS_DIR, f"{safe_ticker}_{timestamp}.csv")
        if trades:
            keys = trades[0].keys()
            with open(csv_path, "w", newline="", encoding="utf-8") as f:
                writer = csv.DictWriter(f, fieldnames=keys)
                writer.writeheader()
                writer.writerows(trades)
            logger.info(f"Saved: {csv_path}")

    # JSON summary semua ticker
    summary = {}
    for ticker, trades in all_trades.items():
        summary[ticker] = {
            "metrics": calculate_metrics(trades),
            "trade_count": len(trades),
        }

    json_path = os.path.join(config.RESULTS_DIR, f"summary_{timestamp}.json")
    with open(json_path, "w", encoding="utf-8") as f:
        json.dump(summary, f, indent=2, ensure_ascii=False)
    logger.info(f"Saved: {json_path}")

    print(f"\nHasil disimpan di: {config.RESULTS_DIR}")
```

## 12. Interpretasi Hasil

### Winrate

| Winrate    | Interpretasi                                              |
|------------|-----------------------------------------------------------|
| < 40%      | Agent sering salah arah. Review prompt dan model.         |
| 40% - 55%  | Rata-rata. Perlu lihat profit factor untuk kelayakan.     |
| 55% - 70%  | Baik. Bisa mulai pertimbangkan paper trading.             |
| > 70%      | Sangat baik. Waspadai overfitting ke periode tertentu.    |

### Profit Factor

| Profit Factor | Interpretasi                                          |
|---------------|-------------------------------------------------------|
| < 1.0         | Sistem merugi secara total.                           |
| 1.0 - 1.5     | Break even atau sedikit profit. Margin tipis.         |
| 1.5 - 2.5     | Solid. Sistem bisa dipertimbangkan.                   |
| > 2.5         | Excellent. Verifikasi data tidak ada lookahead bias.  |

### Expectancy

Ini metrik paling penting. Artinya: berapa persen yang kamu harapkan per trade.

- Positif = sistem profitabel dalam jangka panjang
- Negatif = sistem merugi bahkan jika winrate tinggi

### Yang perlu dicermati setelah hasil keluar

1. Apakah winrate konsisten antar ticker atau satu ticker sangat outlier?
2. Apakah max drawdown lebih besar dari yang bisa kamu tolerir?
3. Apakah trade yang WIN punya confidence score lebih tinggi dari yang LOSS?
4. Apakah ada periode tertentu (misalnya 2023 vs 2024) di mana sistem lebih buruk?

BREN memiliki data historis yang lebih pendek dibanding BBCA, BBRI, TLKM, dan TPIA. Karena itu, dokumen ini sudah menambahkan `TICKER_START_OVERRIDE` di `config.py` dan `signal_generator.py` sudah memakai `effective_start` per ticker.

```python
TICKER_START_OVERRIDE = {
    "BREN.JK": "2023-10-09",
}
```

1. Cek koneksi data Yahoo Finance / `yfinance`.
2. Pastikan ticker ditulis `BREN.JK`, bukan `BREN`.
3. Pastikan `BACKTEST_END` lebih besar dari tanggal override.
4. Cek apakah cache lama berisi sinyal error sebelum override diterapkan. Jika iya, hapus cache khusus ticker tersebut atau set `FORCE_REGENERATE_SIGNALS=true` sementara.

### Error: Pipeline output key tidak ditemukan

Edit fungsi `call_pipeline()` di `signal_generator.py`. Sesuaikan key dengan
